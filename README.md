# React Router DOM

A React application built to practice routing concepts using React Router DOM, including parent-child routing, nested routes, dynamic URL parameters, navigation, and error handling.

## 🚀 Features

- Parent-child routing
- Nested routes
- Reusable parent layout using `Template`
- Child components rendered using `Outlet`
- Navigation using React Router `Link`
- Dynamic URL parameters using `useParams`
- Dynamic welcome message
- Error handling for invalid routes

## 🛠️ Technologies Used

- React
- React Router DOM
- JavaScript
- JSX
- Vite
- CSS
